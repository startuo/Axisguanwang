## 🎨 设计特点

- **主题配色**：暗紫粉色系（`#9333ea` → `#ec4899`），契合游戏辅助菜单的科技与神秘感
- **液态玻璃效果**：基于 `backdrop-filter` 实现的 iOS 26 风格毛玻璃质感
- **几何粒子背景**：全站 Canvas 粒子动画，随鼠标移动激活吸附效果
- **页面加载动画**：Logo 浮动 + 粒子轨道环绕的开场动画
- **响应式布局**：覆盖 1024 / 768 / 480 三档断点，移动端体验完善
- **微交互动效**：卡片悬浮、按钮辉光、图标缩放等细节反馈

## 🚀 快速开始

本项目为纯静态站点，无需任何编译或服务端环境。

### 方式一：直接打开

双击 `index.html` 即可在浏览器中查看。

### 方式二：本地服务器（推荐）

为获得最佳体验（如字体加载、相对路径解析等），建议启动本地静态服务器：

```bash
# Python
python -m http.server 8000

# 或 Node.js（需全局安装 http-server）
npx http-server -p 8000
```

浏览器访问 `http://localhost:8000`。

## ✨ 主要功能模块

### 1. 几何粒子背景
全站固定的 Canvas 粒子层，颜色取自灰浅粉系。鼠标在 200px 半径内可激活粒子吸附与亮度增益效果。

### 2. 液态玻璃导航栏
透明 → 滚动后切换为毛玻璃态。支持滚动方向感知（向下隐藏、向上显示）、当前节区高亮、移动端汉堡菜单。

### 3. 菜单展示画廊与灯箱
- 响应式网格（桌面 3 列 / 平板 2 列 / 移动 1 列），第 5 张横跨 2 列形成视觉重音
- 悬浮时卡片上移、渐变描边浮现、图片轻微放大、放大图标弹出
- 点击打开灯箱：支持左右箭头键、触摸滑动、Esc 关闭、点击遮罩关闭
- 完整的键盘可访问性（`tabindex`、`role`、焦点管理）

### 4. 价格卡片
单卡横向布局，悬浮触发锥形渐变光环旋转动画，强化"免费"卖点。

### 5. 回到顶部按钮
滚动超过 500px 显示，悬浮上移并加强辉光。
